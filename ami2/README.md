# AMI 2.0

Новая версия приложения находится в отдельной папке `ami2/` и разрабатывается в ветке `ami2-development`. Основная ветка `main` и существующее приложение не изменяются.

## Текущий прототип
- Адаптивный интерфейс для телефона и компьютера.
- Разделы: Главная, Рынок, Товары, Деньги.
- Локальный учёт бюджета, закупок, фактических продаж и расходов в браузере.
- Загрузка сохранённой выборки из `../data/avito-results.json`, если её формат совместим.
- PWA manifest и service worker.

## Ограничения первой версии
- Учёт хранится локально в браузере и не синхронизируется между устройствами.
- Рынок показывает только предоставленную API-выборку, а не весь Авито.
- Количество объявлений не является показателем продаж или спроса.
- AI-помощник, мониторинг продавцов и автоматические рекомендации ещё не подключены.
- Не размещайте API-ключи в клиентском коде или публичном репозитории.

## Запуск
Откройте GitHub Pages для ветки/папки после настройки публикации. До включения публикации можно открыть `ami2/index.html` локально, но загрузка рыночного JSON и PWA могут работать только через HTTP(S).
